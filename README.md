# Portfolio MDCU Applicant

เว็บไซต์ Portfolio แบบหน้าเดียว (One-Page) สำหรับยื่นสมัครเข้าศึกษาต่อคณะแพทยศาสตร์ จุฬาลงกรณ์มหาวิทยาลัย

## รายละเอียดโปรเจกต์
- ใช้ HTML5 + Tailwind CSS ผ่าน CDN
- ใช้ Vanilla JavaScript สำหรับเมนูมือถือแบบ Hamburger
- ออกแบบให้ Responsive และดูสวยบน Mobile / Tablet / Desktop
- มี section สำหรับ About, Skills, Projects, Contact และ Footer

## วิธีเปิดดู
1. เปิดโฟลเดอร์โปรเจกต์ใน VS Code
2. เปิดไฟล์ index.html
3. ใช้ Live Server เพื่อดูหน้าเว็บ

## ไฟล์หลัก
- index.html: โค้ดหน้าเว็บทั้งหมด

## ข้อมูลที่สามารถแก้ไขได้
- ชื่อ-นามสกุลใน Hero Section
- อีเมลและเบอร์โทรศัพท์ในส่วน Contact
- เนื้อหาใน section About, Skills และ Projects
- ภาพตัวอย่างที่ใช้ในโครงสร้างเว็บไซต์

## หมายเหตุ
โปรเจกต์นี้ถูกออกแบบให้เป็นไฟล์เดียวและสามารถรันได้ทันทีโดยไม่ต้องติดตั้ง dependency เพิ่มเติม
